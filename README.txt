NEXORA AI WEBSITE STARTER
=========================

This is a responsive, single-page starter website for Nexora AI.

FILES
- index.html: website content and structure
- styles.css: layout, colours and responsive styling
- script.js: mobile navigation and current year

BEFORE PUBLISHING
1. Open index.html.
2. Find: YOUR_EMAIL@example.com
3. Replace it with a real business email address.
4. Review every service statement and make sure it reflects what you can currently deliver.
5. Add your real phone number, LinkedIn page and any verified business details if desired.

PREVIEW
- Extract the ZIP file.
- Open index.html in a browser.
- For local development, you can also open the folder in VS Code and use the Live Server extension.

FREE DEPLOYMENT OPTION: GITHUB PAGES
1. Create a GitHub repository, for example: nexora-ai-website.
2. Upload index.html, styles.css and script.js to the repository root.
3. In the repository, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. Wait for GitHub Pages to publish the site.

NOTES
- This is a static marketing website. It does not include a backend, working enquiry database, analytics, authentication or chatbot.
- The email button uses a mailto link. It opens the visitor's email application.
- Google Fonts requires an internet connection; fallback fonts are included.
- Nexora AI is a proposed working brand name. Check legal and domain availability before formal use.
